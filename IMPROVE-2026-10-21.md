## Preserve into v3 docs before archiving (unique to v1)

- **`src/crawler/safety.ts`** — the SSRF guard is already ported to v3, but its *documentation value* is here: it is a deliberate superset union of crawlstr's and indexstr's ranges, handles the odd IPv4 forms browsers accept (integer/hex/octal/short) and unfolds IPv4-embedded IPv6 transition forms (::ffff:, NAT64, 6to4, Teredo). Worth a "hardening notes" section in v3 docs crediting this design.
- **Random Scout weighted seed strategy** (40% fresh / 25% rare / 15% category / 10% stale / 10% random) and the one-category-per-`.txt` seed corpus pattern (`src/data/seeds/`).
- **Relay auto-discovery flow**: NIP-66 kind 30166 monitor scan → filter NIP-50 → live NIP-11 capability probe (`uncaged_index` block) → one-click add, never automatic. This is the ecosystem's reference implementation of careful relay discovery.
- **Honest-limitations writing** (CORS proxy trade-off, proxy-boundary SSRF residual gap) — keep this tone in v3 docs.
